01

Vision–Language–Action Model for Construction Automation

Python · LLaMA 3.2 1B · YOLO-World v2 · LoRA · Unsloth · WandB

An end-to-end pipeline for grounded instruction-following in wheel-loader operation. The system runs YOLO-World detection over dashcam frames, formats the detections into a scene-grounding prompt, and feeds that into a LoRA-fine-tuned LLaMA 3.2 1B to produce contextual responses to commands like "Where should I go next?" or "Go to the nearest pile and fill the bucket."

The data pipeline auto-generates VQA training pairs by passing verified pile-detection frames through GPT-4o, then converts the resulting JSONL into HuggingFace dataset format for LoRA fine-tuning. The full inference path produces both annotated frames and structured JSON describing the scene and the model's grounded response.

02

Group Relative Policy Optimization on Countdown

Python · Qwen2.5-1.5B · GRPO · RL · HuggingFace · WandB

A from-scratch reimplementation of Group Relative Policy Optimization — the RL algorithm popularized by DeepSeek-R1 — applied to a Qwen2.5-1.5B language model on the Countdown number-puzzle reasoning task. The setup: given a target integer and a small set of operands, the model must output a sequence of arithmetic operations that reach the target.

Includes a configurable dataset generator (operand count, target range, sample size), a flexible training script supporting both HuggingFace and JSON dataset modes, and full hyperparameter exposure for ε, β, μ, batch size, generation count, and learning rate.

03

Cross-Lingual Reddit Subreddit Classification

Python · NLTK · spaCy · scikit-learn · SVM · SGD · Naive Bayes

Four-way classification of 1,400 Reddit posts to one of Montreal, Melbourne, London, or Paris. The corpus is mixed English (≈74%) and French (≈26%), so the preprocessing pipeline language-detects each sample and applies the matching lemmatizer (WordNet for English, French LEFFF for French) along with combined NLTK + spaCy stopword removal across both languages.

Four models were compared: Naive Bayes implemented from scratch with no ML libraries, plus Logistic Regression, linear SVM, and SGD with Huber loss. SGD-Huber and SVM tied at the top with mean 10-fold validation errors of 28.6% and 28.4%, with SGD edging ahead at 72.8% accuracy on the Kaggle leaderboard.

04

Snake with Tabular Q-Learning from Scratch

Summer 2023 · Python · Pygame · Gymnasium · Stable-Baselines3 · PPO · A2C

A self-directed RL playground. The environment, written from scratch in Pygame and wrapped to the OpenAI Gymnasium interface, allows the same training harness to swap between a custom tabular Q-learning agent and Stable-Baselines3's A2C and PPO. State is encoded as the apple's quadrant (8 directions) plus three boolean wall/body danger flags around the head; actions are turn-left / continue / turn-right.

The reward function is intentionally minimal: +100 for eating the apple, −1 per step (to encourage efficiency), and −500 for any collision. After 500 training episodes, the tabular Q-learning agent reaches 51 points in evaluation.

05

Trajectory Metaheuristics for CNN Hyperparameters

Python · TensorFlow · Tabu Search · Simulated Annealing · Iterated Local Search · CIFAR-10

From-scratch implementations of Tabu Search, Simulated Annealing, and Iterated Local Search applied to the architectural hyperparameters of an image-classification CNN trained on CIFAR-10. The objective balances accuracy against test-time latency:

Objective = (Accuracy²) / Latency

Each metaheuristic improved on the default hyperparameters along both axes. ILS produced the best overall result: +4 percentage-point accuracy gain (68% → 72%) and 16.3% latency reduction. Simulated Annealing converged to comparable latency in a fraction of the wall-clock time — pointing to a useful intensification/diversification trade-off, where ILS and TS were needed for accuracy gains but SA alone was sufficient when latency was the priority.

06

Dashcam Traffic Counting with YOLO & Optical Flow

Python · OpenCV · YOLOv8 · Farneback Flow · K-Means

A computer vision pipeline that counts moving cars, parked cars, and pedestrians from real-world dashcam footage shot in downtown Montreal. YOLOv8 handles detection and tracking; bounding-box position thresholds (40% of screen for people, 26.5% for cars) decide when an object has been "passed" — calibrated to balance recall against double-counting under occlusion.

Moving-vs-parked classification runs in two stages. An initial guess uses screen-region heuristics — moving cars travel down the centre lane, parked cars line the curb. The refinement stage applies K-Means (K=2) on Farneback optical-flow magnitudes, exploiting the consistent ordering flow(same-dir) < flow(parked) < flow(opposite-dir), with the heuristic guess seeding the cluster initialization. Final grade: 93%.
